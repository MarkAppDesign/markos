MarkOS

Privacy policy

Last updated 22 October 2026.

Who uses MarkOS

MarkOS is a personal dashboard used only by its owner. It has no other users and no sign-up. It runs on a private server that can only be reached from the owner's own devices.

What Google data MarkOS uses

When the owner connects their Google account, MarkOS asks for the narrowest access it needs:

  • See the list of calendars, so the owner can choose which ones to show.
  • See calendar events, to show them on the dashboard alongside tasks and the weather.
  • Create and change calendars that MarkOS made itself: one for events added from the dashboard and one for birthdays and anniversaries. MarkOS cannot change or delete anything in any other calendar.

How the data is kept

  • A copy of calendar events (from two months ago to about a year ahead) is kept on the owner's private server so the dashboard loads quickly. It is refreshed every few minutes.
  • The sign-in Google provides is stored encrypted.
  • The server's backups are encrypted.

Sharing

Google data is not sold, shared with anyone, used for advertising, or used to train AI models. It is only shown to the owner, on their own devices.

MarkOS's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Other services

To show the weather, MarkOS sends Open-Meteo a rough location (rounded to about 1 km) and sends OpenStreetMap's Photon search the place names of events. No names, event titles or account details are sent.

Removing access

The owner can disconnect Google at any time in MarkOS's settings, which also cancels the access at Google and deletes the stored copy of calendar events. Access can also be removed at myaccount.google.com/permissions.
